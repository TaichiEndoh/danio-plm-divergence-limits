# Data Availability for the submission snapshot

The retained protein sequences, saved pooled embeddings, analysis code and per-analysis outputs are archived in version v0.1.0-review.20260928 of the study repository at https://github.com/TaichiEndoh/danio-plm-divergence-limits. The repository is temporarily private during peer review; the corresponding authors can provide the matching archive to the editorial office for confidential review. Historical model-weight hashes, complete annotation snapshots and raw variant-score distributions are not available for all analyses.

This statement describes the current review-stage access arrangement. It does not claim that editors already have access, that the repository is publicly accessible, or that a DOI exists. The corresponding author must arrange actual file delivery or access through the editorial office. Update the statement once public access is enabled.
