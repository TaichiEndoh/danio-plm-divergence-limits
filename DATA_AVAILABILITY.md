# Data Availability Statement

The retained protein sequences, saved pooled embeddings, analysis code and per-analysis outputs are openly available in the study repository at https://github.com/TaichiEndoh/danio-plm-divergence-limits, release v1.0.0 (https://github.com/TaichiEndoh/danio-plm-divergence-limits/releases/tag/v1.0.0). Historical model-weight hashes, complete annotation snapshots and raw variant-score distributions are not available for all analyses.

The release page provides the downloadable archive, SHA-256 checksum and Git commit identifier. No DOI has been assigned.
